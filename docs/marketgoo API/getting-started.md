The **marketgoo** API is based on REST principles and follows the recommendations set forth
in the [**json:api** specification](http://jsonapi.org).

The API end-point uses the domain configured as part of your **marketgoo integration** with
the `/api` prefix at the beginning of the path. We will use the domain `app.acmeseo.com/api`
as an example end-point domain through this documentation, but remember to use your assigned
production domain.

The sections below apply both to the Provisioning API and the Data API. This is because the
Data API is really a sub-set of the Provisioning API. You can read more information about
the Data API in the **Data API features** section in the API Reference.
